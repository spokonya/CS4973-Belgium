# Team posts homepage photos

Add **6–8** JPEGs to this folder. Only files that exist are shown (missing slots are skipped).

## File names (use exactly)

| File | Position in staggered grid |
|------|----------------------------|
| `photo-01.jpg` | Top of left column |
| `photo-02.jpg` | Top of right column (slight offset) |
| `photo-03.jpg` | Row 2, left |
| `photo-04.jpg` | Row 2, right |
| `photo-05.jpg` | Row 3, left |
| `photo-06.jpg` | Row 3, right |
| `photo-07.jpg` | Row 4, left (optional) |
| `photo-08.jpg` | Row 4, right (optional) |

You need at least **photo-01** through **photo-06** for a full-looking grid; **07** and **08** are optional extras.

Paths are listed in `content/team_posts/_index.md` under `bentoImages` if you want custom alt text.
